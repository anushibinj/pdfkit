# Styling instructions

- Do not add a footer anywhere in the app. There is no site-wide footer; keep `layout.tsx` free of one.
- Do not add explanatory or disclaimer text beneath the file drop area on tool pages (e.g. the PDF Unlocker). The dropzone's own built-in hint is the only text there.
- Do not add badges or tags (e.g. "Private, runs locally") to the bottom of any tool card on the home page. Cards show only the icon, name and description.
- The home page tool grid ends with a "More tools on the way" placeholder card: grey text, dotted border, not a link. Keep it as the last card.
